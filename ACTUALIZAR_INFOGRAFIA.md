# Corrección de infografía · versión 3.1

La imagen original está integrada en index.html. Su vista, ampliación y descarga ya no dependen de la ruta pública assets/infografia.png.

1. Extrae este ZIP.
2. En GitHub abre el repositorio sistemas-integrados-cafe-pop y entra en Code.
3. Desde la raíz, selecciona Add file > Upload files.
4. Arrastra únicamente el nuevo index.html, sin la carpeta que lo contiene.
5. Confirma el cambio en main con Commit changes.
6. Espera a que Actions termine la publicación de Pages.
7. Abre la página pública y recarga con Ctrl + F5.

El archivo index.html tiene aproximadamente 3,6 MB, por debajo del límite de carga web de GitHub. Conserva el resto de archivos ya publicados. El ZIP incluye también el sitio completo y la imagen PNG original en assets para futuras ediciones.

Para cambiar esta infografía en el futuro, también debe actualizarse la imagen integrada en el bloque embedded-infographic de index.html. Sustituir únicamente el PNG externo no modifica esa copia integrada.
